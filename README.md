# Fasal Raksha

A unified, farmer-first Progressive Web App (PWA) that bridges the communication gap between rural communities and forest/agriculture officers.

## 🎯 Mission

Enable farmers to instantly report crop damage, wildlife encounters, and property loss — while giving forest officers a real-time command dashboard to respond, manage crowds, and coordinate compensation.

## 🧱 Tech Stack

**Frontend:** React 18 + TypeScript + Vite + Tailwind CSS + Leaflet + Framer Motion + TanStack Query

**Backend:** FastAPI + SQLAlchemy 2.0 + Pydantic v2 + JWT Auth

**Database:** SQLite (dev) → PostgreSQL + PostGIS (prod)

**AI/ML:** Ultralytics YOLOv8 (with Demo Mode fallback)

**Real-time:** Socket.IO
